ATELIER FAYET 33 — MISE À JOUR 45

PRÉREQUIS
Cette mise à jour s’applique après la MAJ44.
Si son script SQL n’a pas encore été exécuté, applique d’abord
supabase/44-signatures-presence.sql depuis l’archive MAJ44.

1 — SUPABASE, AVANT DE METTRE À JOUR LE SITE
Ouvre ton projet Supabase > SQL Editor > New query.
Ouvre le fichier supabase/45-ventes-additionnelles.sql de cette archive.
Copie tout le contenu dans SQL Editor et clique sur Run.
Attends le message de réussite.
Le script peut être réexécuté ; il ne supprime pas les données existantes.

Il ajoute le suivi des ventes et leurs corrections. Les objectifs déjà
importés depuis les PDF restent conservés dans leur table existante.

2 — GITHUB ET CLOUDFLARE
Décompresse l’archive, puis mets à jour les fichiers du projet GitHub :
- src et public ;
- supabase ;
- index.html ;
- package.json et package-lock.json ;
- tsconfig.json, vite.config.ts et postcss.config.js.

Cette archive contient uniquement le nouveau guide et le nouveau script SQL.
Tu peux retirer du dépôt les anciens guides et scripts SQL de mise à jour.
Cela n’efface pas les données Supabase.

Conserve les variables de BUILD déjà configurées sur Cloudflare.
N’ajoute pas de fichier _redirects.
Aucune nouvelle clé, aucun service payant ni redéploiement d’Edge Function
n’est nécessaire pour cette mise à jour.

Attends le déploiement Cloudflare réussi, puis ferme et rouvre l’application.
Vérifie que MAJ45 apparaît dans le pied de page.

3 — NOUVEAU MENU
Clique sur le bloc Menu qui indique la rubrique actuellement ouverte.
Un panneau présente toutes les rubriques autorisées, avec leurs textes
et pictogrammes conservés. Clique sur une rubrique pour l’ouvrir.
La cloche et le profil restent accessibles en haut de l’application.
Le panneau fonctionne en mode clair et sombre, sur mobile et ordinateur.

4 — CIBLES DU JOUR ET VENTES ADDITIONNELLES
Le cadre et ses cases sont plus compacts.
Chaque case indique les ventes réalisées / l’objectif importé, par exemple :
0/3 : aucune vente ;
3/3 : objectif atteint ;
5/3 : objectif dépassé, fond vert clair et bordure vert foncé.

Les cinq catégories restent indépendantes :
Purge de freins, Batteries montées, BEG, Géométrie et Clim.
Le décompte correspond au total de l’équipe pour la journée sélectionnée.

Pour ajouter une vente :
- Clique sur la case concernée.
- Vérifie la catégorie et la journée.
- Clique sur Ajouter 1 vente.

Pour un collaborateur :
- La saisie se fait uniquement sur la journée actuelle, heure de Paris.
- Une vente maximum toutes les 10 minutes, toutes catégories confondues.
- Le délai restant apparaît dans le cadre.
- La limite est vérifiée par Supabase, même avec plusieurs onglets/appareils.
- Une correction ou une annulation ne remet pas ce délai à zéro.

Administrateur et modérateurs :
- Pas de délai de 10 minutes.
- Possibilité d’ajouter une vente sur la journée sélectionnée, y compris passée.
- Accès à Suivi des ventes pour consulter et corriger les quantités.

Les invités restent en consultation seule.
Sans objectif PDF, le compteur affiche par exemple 2/— ; les ventes peuvent
tout de même être saisies aujourd’hui. Elles restent conservées après import.
Le vert apparaît uniquement lorsqu’un objectif renseigné est dépassé.

5 — CONSULTER ET CORRIGER LES QUANTITÉS
Administrateur ou modérateur : clique sur Suivi des ventes.
Tu vois la catégorie, le nom de l’auteur, la date, l’heure et la quantité.
Tu peux filtrer par catégorie.

Modifie la quantité et clique sur Enregistrer :
- 0 annule la vente dans le total sans effacer sa trace ;
- une quantité positive remplace la quantité de cette saisie ;
- chaque correction conserve l’ancienne quantité, la nouvelle,
  le nom de la personne qui corrige et l’heure.

Si quelqu’un a déjà modifié la même vente, un message demande d’actualiser.
Les collaborateurs ne peuvent ni ouvrir cet historique ni corriger une vente.

6 — ACTUALISATION
Les compteurs s’actualisent après chaque ajout/correction, au retour sur
l’application et toutes les 30 secondes.
L’import PDF reste disponible pour l’administrateur.
