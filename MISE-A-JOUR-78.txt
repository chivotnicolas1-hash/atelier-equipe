ATELIER FAYET 33 — MISE À JOUR 78

INSTALLATION (après les migrations 75 et 76)
1. Supabase > SQL Editor > New query : colle TOUT le contenu de
   supabase/78-import-catalogues.sql, puis Run. Attends Success.
   Le correctif 77 de suppression et son correctif WHERE sont inclus.
2. Remplace les fichiers du projet GitHub avec ceux de cette archive.
   Avec GitHub Desktop : copier les fichiers dans le dossier du dépôt,
   vérifier les changements, écrire un résumé, Commit to main puis Push origin.
3. Conserve tes variables de build Cloudflare. Attends la réussite du déploiement.
4. Ferme puis rouvre l’application. Aucun fichier _redirects ne doit être ajouté.
Aucune Edge Function ni clé API supplémentaire à installer pour cette mise à jour.

NOUVEAUTÉS — ESPACE ADMINISTRATEUR, CONSOMMABLES
Chaque section (Pneus, 5gaz, Freins/transmissions/roulements, Divers liquides)
possède un pictogramme, « Créer un consommable » et « Mettre à jour depuis un PDF ».
Les droits des autres utilisateurs pour les commandes restent inchangés.

CRÉER AVEC PHOTO
- Clique sur Créer un consommable dans la section voulue.
- Saisis la désignation et joins, si souhaité, une image JPEG, PNG ou WebP.
- Vérifie l’aperçu, puis Publier les changements et confirmer.
- Pour modifier une photo existante, sélectionne l’article dans « Associer à ».
  Vérifie la désignation dans le champ : elle sera aussi enregistrée.
- La photo est redimensionnée avant enregistrement. L’ancienne photo du produit
  est remplacée, sans conserver de copie supplémentaire dans son catalogue.

MISE À JOUR PDF
1. Ouvre Mettre à jour depuis un PDF dans la section concernée.
2. Choisis le PDF (texte sélectionnable, 20 Mo et 15 pages maximum).
3. Vérifie la colonne des désignations. Par défaut : entre 20 et 68 % de la largeur.
   Utilise « Ajuster la colonne » et Relire le PDF si nécessaire.
4. Consulte le document original dans l’aperçu. Corrige les désignations,
   ignore les titres, fusionne les lignes appartenant au même article si besoin.
5. Les noms identiques sont associés automatiquement aux produits existants.
   Pour un nom modifié, choisis manuellement l’article dans « Associer à ».
6. Les ajouts sont marqués en vert, les mises à jour en bleu, les retraits en rouge.
   Coche chaque changement que tu souhaites publier. Rien n’est coché automatiquement.
7. Les photos actuelles sont conservées. Tu peux en joindre une nouvelle par ligne.
   Cette version ne découpe pas automatiquement les photos à partir des pages PDF.
8. Les articles absents du PDF restent conservés. « Retraits facultatifs » permet
   de préparer un retrait explicite, à cocher puis confirmer avant publication.
9. Clique Publier les changements. Annuler ou fermer avant publication n’écrit rien.

PDF scanné (image sans texte) : non reconnu dans cette version.
Utilise un PDF avec texte sélectionnable ou la création manuelle avec photo.
La lecture se fait sur ton appareil, sans service d’IA ni coût d’API.
Le PDF et le brouillon ne sont pas conservés après fermeture.

PARTICULARITÉ DIVERS LIQUIDES
Les positions, types, conditionnements, couleurs et photos existants sont conservés.
Les nouveaux articles sont ajoutés dans « Autres liquides », sans conditionnement.
Ouvre ensuite « Modifier le plan et les boutons » pour renseigner le conditionnement,
choisir huile/cuve/autre liquide et régler la position. Les règles de commande en cuve
(minimum 500 L) restent inchangées.
Le retrait d’une huile du plan conserve les anciennes lignes de commandes, comme avant.
Pour les trois autres catalogues, le retrait supprime la fiche, sa photo et ses lignes
identifiées dans les commandes, conformément au fonctionnement de la mise à jour 77.
Les anciens PDF exportés, sauvegardes et historiques GitHub ne sont pas supprimés.

PROTECTION DES DONNÉES
- Publication réservée à l’administrateur côté serveur.
- Un lot invalide est annulé entièrement pour les trois catalogues.
- Si le contenu a changé pendant la préparation, le serveur refuse l’écrasement.
  Ferme le brouillon puis rouvre-le pour repartir sur la version actuelle.
- Le simple reclassement des produits par fréquence de commande ne bloque pas l’import.
- Aucun produit existant n’est réinitialisé par l’exécution du SQL 78.
