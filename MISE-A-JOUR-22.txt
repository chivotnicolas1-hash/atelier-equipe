LES 7 MODIFICATIONS
1. Barre du haut bleu très clair en mode clair.
2. Bouton lune/soleil en haut à droite pour changer de mode. Choix mémorisé dans le navigateur de cet appareil, également disponible à la connexion.
3. Objectif du jour de nouveau vert (adapté au mode sombre).
4. Notifications en bas de Mon profil, après les réglages de photo.
5. Configurer ouvre directement cette section du profil.
6. Administration > Équipes > Modifier la photo : choisir ou supprimer, puis Enregistrer. Le collaborateur doit avoir un compte de connexion créé. Il conserve également la possibilité de modifier sa propre photo.
7. Administration > Objectif du jour atelier > Modifier l’objectif : montant de la date actuellement sélectionnée. Vérifier cette date avant de modifier. L’extraction du PDF reste disponible. Par défaut elle conserve les objectifs existants ; le remplacement explicite permet de les écraser. Une modification concurrente est signalée au lieu d’être écrasée.

INSTALLATION DEPUIS LA MISE À JOUR 21

1 — SUPABASE (À FAIRE EN PREMIER)
Ouvre supabase/22-reglages-administrateur.sql dans ce ZIP avec un éditeur texte.
Copie tout son contenu.
Dans ton projet Supabase : SQL Editor > nouvelle requête, colle le script puis Run.
Attends le succès. Ce script ajoute deux fonctions réservées à l’administrateur. Il ne supprime aucune donnée et peut être réexécuté.

2 — GITHUB
Décompresse le ZIP. Dans ton dépôt, remplace :
- src/main.tsx
- src/workshop.tsx
- src/profile-announcement.tsx
- src/globals.css
Ajoute :
- src/theme.tsx
- src/admin-settings.tsx
- supabase/22-reglages-administrateur.sql (conserver le script dans le projet)
Tu peux aussi envoyer l’ensemble des fichiers du ZIP en conservant leurs dossiers.
Valide les changements sur la branche reliée à Cloudflare.

3 — CLOUDFLARE
Attends le nouveau déploiement réussi puis recharge l’application.
Aucune nouvelle variable, clé ou Edge Function à configurer.
Si les nouvelles options manquent, ferme puis rouvre l’application et vérifie que le déploiement correspond au dernier commit GitHub.

VÉRIFICATIONS RÉALISÉES
Compilation de production ; essais navigateur admin, modérateur et collaborateur sur ordinateur/mobile ; persistance du thème ; accès direct aux notifications ; modification/suppression des photos et modification de l’objectif.
