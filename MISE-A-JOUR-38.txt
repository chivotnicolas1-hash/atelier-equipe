INSTALLATION APRÈS LA MISE À JOUR 37
1. Décompresse cette archive.
2. Dans Supabase > SQL Editor > New query, colle le contenu COMPLET de
   supabase/38-signalements-litiges.sql puis clique sur Run.
   Attends le message Success. Ce script peut être réexécuté.
3. Remplace dans ton dépôt GitHub les dossiers src, public et supabase,
   ainsi que les fichiers de la racine fournis dans cette archive :
   package.json, package-lock.json, index.html, vite.config.ts,
   tsconfig.json et les autres fichiers de configuration présents.
   Conserve tes variables de build Cloudflare et tes secrets Supabase.
   Ne crée pas de fichier _redirects.
4. Enregistre les changements sur la branche liée à Cloudflare.
5. Attends le succès du déploiement, ferme puis rouvre l’application.
   Si nécessaire, actualise complètement la page dans le navigateur.

Aucune fonction Edge à redéployer. Aucun nouveau secret à créer.
Les migrations des versions précédentes doivent déjà être installées.
Ne désinstalle pas les anciennes fonctions SQL : certaines sont réutilisées.

3 — LITIGES EN COURS
Administrateur et modérateurs peuvent choisir Niveau 1, 2 ou 3 dans le
formulaire. Une nouvelle fiche propose le niveau 1 par défaut.
Les anciennes fiches indiquent « Niveau à préciser » jusqu’à leur édition :
aucun niveau n’est inventé pour l’historique.
Lecture réorganisée : client, plaque, badges de niveau/statut, situation,
suivi et prochaines actions, auteur et heure de la dernière mise à jour.
Seul l’administrateur peut supprimer un litige, après confirmation.
La suppression est définitive. Les modérateurs n’ont pas ce droit,
y compris côté serveur. Une modification concurrente bloque la suppression
jusqu’à actualisation, afin de ne pas effacer une version non consultée.

4 — UN SEUL PLAN DE L’ATELIER
Le menu contient une seule entrée « Plan de l’atelier » pour tous les profils.
- Écran de 900 pixels CSS ou moins : présentation mobile V2.
- Écran plus large : présentation initiale V1.
Le changement est automatique lorsque la largeur de la fenêtre change.
La V2 n’est donc plus une page séparée réservée à l’administrateur.
Positions, double affectation géométrie, horaires et coupures restent gérés
comme avant. Les droits restent inchangés : seuls les gestionnaires peuvent
modifier les affectations ; les autres profils consultent le plan.
