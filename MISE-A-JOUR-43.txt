ATELIER FAYET 33 — MISE À JOUR 43
Notifications supprimables et cibles du jour · ZIP nettoyé

INSTALLATION
Ce ZIP met à jour TON APPLICATION EXISTANTE. Il ne sert pas à créer une
base Supabase vide. Prérequis : MAJ40 minimum déjà installée.
Les correctifs MAJ42 sont inclus et peuvent être rejoués sans perte de données.

1. Décompresse l’archive.
2. Supabase > SQL Editor > New query : copie TOUT le contenu de
   supabase/43-mise-a-jour.sql et clique sur Run. Attends Success.
3. Remplace sur GitHub les fichiers du projet par ceux du ZIP.
   Lis NETTOYAGE-GITHUB.txt : téléverser ne supprime pas les anciens fichiers.
   Conserve tes variables de build Cloudflare et tes secrets Supabase.
   Ne téléverse pas node_modules ou dist. N’ajoute aucun _redirects.
4. Attends la réussite du déploiement Cloudflare puis ferme et rouvre l’appli.
   Sur ordinateur, un rechargement Ctrl+F5 récupère les fichiers récents.
   Le pied de page doit afficher MAJ43. Sinon, vérifie que le déploiement
   Cloudflare utilise le dernier commit de ton dépôt GitHub.

Aucune nouvelle clé API. Aucune Edge Function à redéployer pour cette mise à jour.
L’import du PDF se fait sur ton appareil et n’utilise aucune IA payante.

NOTIFICATIONS
Mes notifications contient :
- Supprimer cette notification, bouton rouge sur chaque carte ;
- Tout supprimer, avec confirmation, pour tes notifications uniquement ;
- Afficher les notifications lues, pour pouvoir les supprimer également.
Par défaut, seules les non lues sont affichées comme auparavant.
Marquer comme lue retire la notification de cette vue et du compteur.
La suppression ne touche pas les autres destinataires.
Tout supprimer agit aussi sur les anciennes notifications hors des 100
entrées les plus récentes retournées dans la liste.
Le texte supprimé est effacé. Une trace technique minimale de l’événement
est conservée pour ne pas recréer un rappel programmé déjà supprimé.
Cela ne retire pas une notification déjà affichée par Android ou iOS.

CIBLES DU JOUR
Le cadre est placé sous Objectif du jour atelier, sur les mêmes pages.
Il affiche Purge de freins, Batteries montées, BEG, Géométrie et Clim pour
la date choisie. Tous les utilisateurs peuvent consulter ces valeurs.
L’import est réservé à l’administrateur, comme l’import du planning.
Les cibles restent séparées du chiffre d’affaires, du ratio et des horaires.

IMPORTER LE PDF A4 CENTRE
1. Dans Cibles du jour, clique sur Importer les cibles PDF.
2. Vérifie l’année du document. Elle peut ne pas être indiquée dans le PDF.
3. Choisis ton PDF A4 centre, distinct du PDF des horaires Orquest.
4. Vérifie l’aperçu. Décoche les dates que tu ne souhaites pas importer.
5. Confirme l’année, le centre et les valeurs affichées, puis Enregistrer.
6. Change la date de l’application pour consulter les cibles d’une autre journée.
L’import enregistre toutes les dates sélectionnées, pas uniquement celle
qui était affichée au moment de l’ouverture du formulaire.
Sans Remplacer, les valeurs existantes sont conservées.
Avec Remplacer, seules les dates sélectionnées sont remplacées.
Une date non importée affiche des tirets et Aucune cible importée.
Un zéro reste un zéro : il n’est pas confondu avec une donnée manquante.

DOCUMENT FOURNI
Enjeux saison - A4 centre.pdf permet de lire les dates du 1er au 27 octobre.
Les dates des dernières lignes sont coupées : elles sont ignorées.
Réexporte le tableau avec toutes les dates visibles pour importer la fin
du mois. Aucune date manquante n’est inventée.
Confirme 2026 si le document correspond bien à octobre 2026 : les jours
imprimés sont cohérents avec cette année. L’import vérifie cette cohérence.
Exemple du 17/10/2026 : purge 4, batteries 4, BEG 37, géométrie 8, clim 2.
Les totaux, quantités réalisées, écarts et pourcentages ne sont pas utilisés.
Seules les valeurs confirmées sont enregistrées dans Supabase, pas le PDF.
Limites : PDF texte A4 centre, sept groupes et colonnes Cible visibles,
maximum 10 Mo, 12 pages, une seule ligne par date. Un scan ou une autre
présentation peut nécessiter un nouvel export.

ZIP NETTOYÉ
Anciens guides, SQL historiques, générateurs inutilisés, configurations
Netlify/Vercel, icônes inutilisées et débrief ne sont plus inclus.
Les sources, configurations, deux fonctions actives, OCR, polices et licences
utiles sont conservés. Aucun fichier de données personnelles n’est inclus.
Le script SQL fourni met à jour la base existante : ne recrée pas le projet
Supabase et ne supprime aucune table, compte, fonction active ou tâche Cron.
Si l’ancienne fonction workshop-debrief existe encore dans Supabase, elle
peut être supprimée. Le SQL fourni bloque déjà son accès côté application.
